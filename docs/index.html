Why this exists

AI coding assistants are fast. They are also undisciplined by default. The same session that writes clean code will also skip UX thinking, miss accessibility on user-facing screens, claim "it's done" based on belief rather than evidence, and ship LLM features with no token budget, no adversarial test, and no observability.

These are not model failures. They are process failures. Dharma 1.0 solves process failures without slowing you down.

The three bets

01 — Velocity

Roles, not prompts

23 named skills with decision frameworks. CEO scopes. Designer rates 8 dimensions. QA opens a real browser. Specialization compounds.

02 — Discipline

Evidence over belief

"Should work" is banned at commit time. Five valid completion states only. Auth/payments/AI diffs trigger forced gates before push.

03 — AI-native

LLMs as production

First framework with executable economics + safety eval + observability. Token budgets, adversarial tests, drift detection. 38 unit tests, pure stdlib.

Install — 60 seconds

git clone https://github.com/SahuDilip1356/dharma-1.git
cd dharma-1
./install.sh /path/to/your/project

Copies the 23-skill catalog. Installs commit-msg and pre-push git hooks. Scaffolds 3-drawer memory. Wires the router + AI overlay. Requires Python 3.9+ and Git. No external SDKs.

Your first run

$ .dharma/dharma route "add a chatbot for patient FAQs"

[Route B — New Feature]

  Exit evidence needed:  PRD contract; Plan complete;

The router never auto-executes. It classifies your task and suggests a starting skill plus required gates. The human decides.

The AI overlay — the moat

Drop-in wrapper for any LLM callable. Tracks cost, emits telemetry, enforces budget. Runs adversarial evals. Detects distribution drift. Provider-agnostic. Pure-stdlib Python. 38 tests. 

from ai_runners import AIOverlay, EvalHarness

overlay = AIOverlay(
    model_fn=my_llm,
    model_name="claude-sonnet-4-6",
    ceiling_usd=10.0,
    telemetry_path="logs/llm.jsonl",
)

response = overlay("Summarize this document...")

# Run the safety eval through the same overlay
# (so eval costs are tracked too)
harness = EvalHarness(model_fn=overlay, evals_dir="ai_runners/evals")
print(harness.run_all().summary())
# {'overall_pass_rate': 0.92,
#  'categories': {'jailbreak': {'pass': 5, 'rate': 1.0}, ...}}
